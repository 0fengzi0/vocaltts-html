# VocalTTS 重构版 —— 需求基线与项目方案

> 本文档整理自 2026-08-21 需求讨论对话，作为后续开发与查阅的基准。
> 旧仓库 git 历史保留；前端整体重写，后端基于 `api/` 已有 Go 项目改造。

## 1. 项目概述

在线 TTS 合成网站。**前后端分离部署**：

- **后端**：Go，位于 `api/`（独立 git 仓库），代理调用 HuggingFace 上的 VoxCPM Gradio 空间完成推理
- **前端**：Vue 3 + Vite + Vuetify 3，纯静态 SPA 部署，后端地址通过 `VITE_API_BASE_URL` 环境变量注入
- 默认发音人：洛天依（lty），服务端另有 lty_gan（元气）、lty_91（Vocaloid 调教）变体

## 2. 后端 API 契约（OpenAI 风格）

所有 `/v1/*` 接口需要动态签名鉴权。跨域支持（CORS）已内置。

### 2.1 鉴权方案（动态签名，防重放/白嫖）

| 请求头 | 说明 |
|---|---|
| `X-Timestamp` | Unix 秒时间戳，与服务器偏差超过 ±300 秒即拒绝 |
| `X-Signature` | `hex(HMAC-SHA256(secret, ts + "\n" + METHOD + "\n" + path + "\n" + body))` |

- `secret` 为前后端共享密钥，硬编码于后端 `main.go` 与前端配置中，泄露后两端同时更换
- **定位说明**：该方案防抓包重放与接口白嫖；真正防中间人窃听依赖 HTTPS（密钥硬编码在前端代码中本身等于公开）
- 无数据库，无状态

### 2.2 GET /v1/models —— 发音人列表

响应：

```json
{
  "object": "list",
  "data": [
    {
      "id": "lty",
      "object": "model",
      "name": "洛天依·日常",
      "avatar": "https://...",
      "description": "默认音色"
    }
  ]
}
```

`id` 即合成请求中的 `model` 字段。name/avatar/description 为展示扩展字段。

### 2.3 POST /v1/audio/speech —— 语音合成

请求体：

```json
{
  "model": "lty",
  "input": "要合成的文本",
  "mode": "standard",
  "voice_instruction": "语速稍快、开心的语气"
}
```

| 字段 | 标准/扩展 | 说明 |
|---|---|---|
| `model` | OpenAI 标准 | 发音人 code，缺省 `lty` |
| `input` | OpenAI 标准 | 合成文本，上限 500 字符 |
| `mode` | 扩展 | `standard`（默认）/ `emotion` |
| `voice_instruction` | 扩展 | 情感模式控制指令，仅 `mode=emotion` 时生效 |

- **standard**：服务端硬编码参考音频转录文本，最贴近参考音色，前端不可覆盖
- **emotion**：仅用参考音频提取音色，`voice_instruction` 调节情感/语速/风格

响应：**音频二进制流**（`Content-Type` 按音频魔数判定，MP3 为 `audio/mpeg`，WAV 为 `audio/wav`）。错误时使用 OpenAI 风格错误体：

```json
{"error": {"message": "...", "type": "invalid_request_error", "code": 400}}
```

### 2.4 GET /healthz

无需鉴权，返回 `ok`，用于健康检查。

## 3. 前端功能范围

- 发音人选择（数据来自 `/v1/models`）
- 文本输入 → 合成 → 播放 → 下载
- 标准/情感模式切换；情感模式展示控制指令输入框
- 公告组件：读取前端静态目录 `announcements.json`（本地手编，不依赖后端）
- 页脚站点信息：运行起始时间和友情链接读取前端静态目录 `site-meta.json`；版本号直接读取根目录 `package.json` 的 `version` 字段
- 低功耗开关：关闭 3D 渲染，仅保留 2D 动效

## 4. 视觉与动效方向（页面风格）

- **主题**：玻璃拟态（Glassmorphism），明暗双主题可切换
- **主色**：天依蓝 `#66CCFF`
- **字体**：标题使用个性展示字体，正文中文无衬线
- **3D 形象**：粒子天依
  - 自绘风格化天依 SVG 剪影（双马尾、耳机轮廓）— 避开 MMD 模型版权问题
  - Three.js 将剪影采样为数万粒子点
  - 待机态：浮动、呼吸、微光；鼠标/触摸视差扰动
  - 音乐播放器气质的整体界面
  - 暂只做待机动作；播放中频谱律动留作后续扩展

## 5. 关键决策记录

| # | 决策 | 理由 |
|---|---|---|
| 1 | 后端沿用 Go + VoxCPM Gradio 直连 | `api/` 已有完成度高的实现，改动最小 |
| 2 | 接口改 OpenAI 风格 + 自定义鉴权 | 通用性好；无数据库需求下动态签名足够 |
| 3 | 合成响应返回二进制流而非 JSON+base64 | 更贴合 OpenAI 契约，前端播放/下载更高效 |
| 4 | 公告、站点信息放前端静态 JSON 而非后端 | 用户手编方便，免动后端 |
| 5 | 3D 用粒子剪影而非 MMD 模型 | 规避洛天依模型配布规约，风格更独特 |
| 6 | `api/` 保持独立仓库，主仓库 .gitignore 忽略 | 用户已有后端仓库 |
